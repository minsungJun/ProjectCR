# ProjectCR

**3D 룰렛 로그라이크.** 죽음의 문턱에 선 카지노에서, 라운드마다 정해진 회전 수 안에 돈을 불려 납부금을 내야 다음 라운드로 넘어갑니다.
라운드를 통과할 때마다 음료로 판을 유리하게 바꾸고, 상점에서 강화를 사 모아 마지막 라운드까지 버티는 게임입니다.

- 엔진: Unity **6000.3.8f1** (Unity 6.3 LTS), URP 17.3, Linear 색 공간
- UI: UI Toolkit (HUD·메뉴), 3D 태블릿·칩 트레이·서빙 로봇
- 입력: Input System
- 언어: 게임 내 텍스트 한국어

> [!IMPORTANT]
> **`main` 브랜치가 아니라 `feature/roulette-basic` 브랜치를 받아야 합니다.**
> 지금 게임 작업은 모두 `feature/roulette-basic`에 있고, `main`에는 아직 반영되지 않았습니다.
>
> ```bash

> ```
>
> 이미 받았다면 `git checkout feature/roulette-basic` 후 `git pull`.

## 게임 규칙

### 룰렛
- **38칸 해골 휠**: 0~36과 해골 칸 하나. 해골은 항상 1/38 확률로 나옵니다.
- 공이 해골에 떨어지면 그 회전의 베팅은 모두 지고, **남은 돈이 절반**이 됩니다.
- 한 회전에 여러 곳에 걸 수 있습니다. 지급은 원금 포함 배수입니다.

| 베팅 | 배수 | 베팅 | 배수 |
|---|---|---|---|
| 숫자 하나 | ×36 | 식스 라인 | ×6 |
| 스플릿 | ×18 | 컬럼·더즌 | ×3 |
| 스트리트(트리오) | ×12 | 색깔·홀짝·하이로우 | ×2 |
| 코너(퍼스트 포) | ×9 | | |

### 라운드와 납부
- 시작 자금 **100**, 라운드마다 **5회전**.
- 라운드가 끝나면 납부금을 자동으로 냅니다. 납부금은 `120 × 4^(라운드−1)`(5 단위 올림)입니다.
- 못 내면 게임 오버, **10라운드** 납부까지 마치면 게임 클리어입니다.

### 음료 (라운드 통과 보상)
라운드를 통과하면 서빙 로봇이 음료 후보 4잔을 가져오고, 하나를 골라 마십니다. 효과는 그 게임이 끝날 때까지 이어집니다.

| 계열 | 효과 |
|---|---|
| **지급 음료** (6종) | 정해진 대상 하나(1열, 빨강 …)의 당첨금 배율 ×1.5, 잔마다 곱해져 쌓임. 넘버 앱생트는 0을 포함한 숫자 베팅 전체 |
| **확률 음료** (6종) | 정해진 대상 하나의 추첨 가중치 증가(색깔·홀짝·하이로우 +37%, 컬럼·더즌 +26%, 숫자 +17%). 같은 묶음에서 이미 마신 대상이 다시 나올 확률이 높음 |

마신 음료 효과는 태블릿의 **[음료]** 버튼으로 언제든 확인할 수 있습니다.

### 서비스(상점)
2라운드부터, 라운드 첫 회전 전에 태블릿 **[서비스]**로 들어갑니다. 강화는 최대 6칸까지 보유하고, 테이블의 배지로 표시됩니다.

- **집중 강화**: 묶음 하나의 당첨금 증가 + 고른 대상의 등장 확률 증가
- **교차 강화**: 한 묶음이 당첨되면(또는 누적 지급액을 채우면) 다음 회전에 다른 묶음 당첨금 증가
- **납부 지원**: 납부할 때마다 일부 환급
- **특수 강화**: 추가 공, 해골 방어
- **소모품**: 딜러의 귀띔, 더블 업 쿠폰, 회전권, 보험 증서

## 조작

| 입력 | 동작 |
|---|---|
| 판 왼쪽 클릭 | 칩 하나 놓기 (1.5초 누르고 있으면 계속 놓기) |
| 판 오른쪽 클릭 | 칩 하나 빼기 (1.5초 누르고 있으면 계속 빼기) |
| 칩 더미 끌기 | 다른 칸으로 통째로 옮기기(있으면 합침), 판 밖에 놓으면 빼기 |
| 마우스 휠 | 칩 단위 위·아래 (1 → 5 → 10 → … → 5000) |
| 칩 트레이 클릭 | 칩 단위 고르기 |
| 태블릿 버튼 | 회전 · 음료 · 서비스 · 전체 회수 |
| 칸에 마우스 올리기 | 대상 칸 강조, 배율·예상 지급 툴팁 |
| [시점 전환] | 1인칭 둘러보기(오른쪽 드래그로 회전) |
| Esc | 음료 화면 → 서비스 창 → 일시정지 순으로 닫기/열기 |

처음 플레이하면 딜러 튜토리얼이 규칙을 안내합니다. 음료·서비스 안내는 어느 게임이든 처음 그 자리에 왔을 때 한 번 나옵니다.

## 실행

1. `feature/roulette-basic` 브랜치를 받은 뒤(위 안내 참고), Unity Hub에서 **Unity 6000.3.8f1**로 프로젝트를 엽니다.
2. `Assets/Scenes/MainMenu.unity`를 열고 Play. 바로 게임을 보려면 `Assets/Scenes/Roulette.unity`.
3. 빌드 씬 순서: `MainMenu` → `Roulette`. Windows 빌드 프로필은 `Assets/Settings/Build Profiles/Windows.asset`.

### 에디터 전용 디버그
플레이 중 오른쪽 위 **[DBG]** 버튼을 펼치면 **라운드 클리어**, **돈 +100,000**을 쓸 수 있습니다. 이 코드는 `#if UNITY_EDITOR` 안에 있어 빌드에는 들어가지 않습니다.

## 테스트

게임 규칙은 MonoBehaviour와 떨어진 순수 C#(`GameFlowController` 등)이라 EditMode 테스트로 검증합니다.

- Unity: **Window → General → Test Runner → EditMode → Run All**
- 테스트 위치: `Assets/Tests/EditMode` (300개 이상)

## 프로젝트 구조

```
Assets/
├─ Scripts/
│  ├─ Roulette/   휠 정의, 회전 설정(SpinConfig), 결과 추첨, 칸별 확률 계산
│  ├─ Economy/    지갑, 베팅 대상·베팅판, 정산
│  ├─ Flow/       게임 흐름(GameFlowController), 라운드·납부, 밸런스(GameBalance), 씬 진입점(RouletteGame)
│  ├─ Drinks/     음료 정의·후보·효과 상태
│  ├─ Shop/       상점 상품·구매·강화 상태
│  ├─ Tutorial/   딜러 튜토리얼 진행과 대사 데이터
│  ├─ UI/         HUD, 상점·음료 태블릿 화면, 툴팁, 메뉴, 입력(TableBetInput)
│  ├─ View/       휠·공 연출, 카메라, 칩 표시, 태블릿, 서빙 로봇
│  └─ Audio/      BGM·효과음
├─ Data/          ScriptableObject 데이터(휠, 밸런스, 음료, 상점, 튜토리얼 대사)
├─ UI/            UI Toolkit UXML·USS
├─ Editor/        씬·에셋 설정 도구(Tools/ProjectCR 메뉴)
├─ Tests/EditMode EditMode 테스트
└─ Scenes/        MainMenu, Roulette
```

### 설계 원칙
- **결과는 로직이 먼저 정하고, 3D는 그 칸에 멈추는 연출만 합니다.** 물리로 판정하지 않습니다.
- 정적 데이터(ScriptableObject)는 런타임에 고치지 않습니다. 회전마다 `SpinConfig`로 복사해서 강화·음료 효과를 적용합니다.
- 중복 회전·차감·정산은 UI가 아니라 `GameFlowController`가 막습니다.
- 확률 계산은 추첨과 UI 미리보기가 같은 식(`PocketWeightCalculator`)을 씁니다.

자세한 설계는 [`Docs/ProjectCR 설계.md`](Docs/ProjectCR%20설계.md)를 참고하세요.
